# PLP Academy Python Week 4 Assignment: Mastering Functions

This repository contains practical implementations of foundational Python function operations, focusing on argument parsing, default tracking parameters, and return statement delivery mechanics.

## File Breakdown
* **`welcome.py`**: Refactors multi-line repetitive string outputs into a single clean reusable function call layout.
* **`toolbox.py`**: A compilation of operational utility functions evaluating numeric logic, boolean checking expressions, and keyword argument manipulation rules.

## Reflection Metrics
The hardest function to write was the `greet` utility in `toolbox.py`. Managing the dynamic string concatenations while maintaining precise comma layout offsets and checking against structural spacing formatting parameters requires careful arrangement to output matching target strings correctly.
